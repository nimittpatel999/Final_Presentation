# Snake and Ladders (C++)

This is a console-based Snake and Ladders game written in C++.  
The program allows 2–4 players to play a turn-based game with dice rolls, snakes, and ladders.

## Features
- Multiple players
- Random dice rolls
- Snakes and ladders using maps
- Object-oriented design (Player, Board, Game classes)

## How to Run
Compile all files and run:

g++ main.cpp Game.cpp Player.cpp Board.cpp -o game
./game
